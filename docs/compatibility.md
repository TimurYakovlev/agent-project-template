# Совместимость

Каркас предназначен для Codex и Claude Code, когда агенту доступен корень репозитория и разрешено читать его файлы. Он использует общие документы с процессами и отдельные короткие входы для каждого продукта.

## Codex

Codex читает проектные `AGENTS.md` по пути от корня репозитория к рабочей папке. В этом каркасе общие правила находятся в корневом [AGENTS.md](../AGENTS.md). Глобальные инструкции пользователя, вложенные правила и настройки среды также могут влиять на сессию. [Официальная документация OpenAI об AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Проектные навыки размещены в `.agents/skills/<имя>/SKILL.md`. Codex поддерживает явный вызов вида `$project-setup` и выбор навыка по смыслу запроса. Доступность конкретного навыка нужно проверить в текущей сессии. [Официальная документация OpenAI о навыках](https://learn.chatgpt.com/docs/build-skills).

## Claude Code

[CLAUDE.md](../CLAUDE.md) содержит импорт `@AGENTS.md`, чтобы подключать общие правила без второй копии. Claude Code поддерживает такой импорт; относительный путь отсчитывается от файла с импортом. [Документация Claude Code о памяти проекта и импортах](https://code.claude.com/docs/en/memory).

Проектные навыки размещены в `.claude/skills/<имя>/SKILL.md`. Явные команды этого каркаса — `/project-setup` и `/project-task`; описание навыка также помогает Claude Code выбирать его по запросу. Загрузка зависит от режима сессии и действующих настроек. [Документация Claude Code о навыках](https://code.claude.com/docs/en/skills).

## Единые процессы

| Назначение | Codex | Claude Code | Общий документ |
| --- | --- | --- | --- |
| Настройка проекта | `$project-setup` | `/project-setup` | [onboarding.md](onboarding.md) |
| Выполнение задачи | `$project-task` | `/project-task` | [workflows/task.md](workflows/task.md) |

Обе версии входа должны вести к одному документу. Бизнес-правила, этапы и критерии готовности хранятся в общих файлах. Проверяющий скрипт контролирует согласованность входов.

Если навык не появился, можно написать:

> Прочитай AGENTS.md и docs/onboarding.md из корня этого репозитория. Выполни описанный процесс настройки проекта.

Для обычной задачи вместо `docs/onboarding.md` укажите `docs/workflows/task.md`. Этот способ требует фактического доступа агента к файлам.

## Облачные сессии и доступы

Облачной сессии нужно отдельно предоставить репозиторий и права на необходимые действия. Автоматическое обнаружение локальных навыков в облаке не гарантируется. В частности, Claude Code описывает отдельные ограничения для облачных режимов и проектных облачных чатов. Если навык недоступен, используйте явное чтение общих документов. [Ограничения облачных навыков Claude Code](https://code.claude.com/docs/en/skills#use-skills-in-cowork-and-cloud-sessions).

Обычный веб-чат Claude не входит в заявленную совместимость этого комплекта. Наличие файла в репозитории также не подтверждает работу hook, плагина, авторизации или делегирования. Подключения, права и возможность независимой проверки настраивают и проверяют отдельно в той среде, где выполняется задача.

Python 3.11+ нужен только для проверяющих скриптов. Общие инструкции не требуют установки библиотек. Успешная проверка файлов не подтверждает, что агент выполнил процесс: это устанавливают по результату пробной и последующих задач.
