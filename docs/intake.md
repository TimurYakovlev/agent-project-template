# Анкета проекта

Заполняй вместе с агентом. Краткого ответа достаточно.
Для ответа из файлов агент указывает источник; догадка остаётся открытым вопросом.
Этот файл войдёт в Git: чувствительные ответы держи в `.local/`,
а здесь оставь безопасную выжимку.

## Первый круг

1. Как называется проект, для кого он существует и какой результат даёт?
   Ответ: не определено.
2. Какие три задачи ты чаще всего будешь поручать агенту? Приведи один пример.
   Ответ: не определено.
3. По чему ты поймёшь, что такая задача сделана хорошо? Есть принятый пример?
   Ответ: не определено.

## Рабочие материалы

4. Проект начинается с нуля или уже работает? Какие части нужно сохранить?
   Ответ: не определено.
5. Где находятся достоверные материалы: код, документы, данные, записи?
   Что можно включать в репозиторий?
   Ответ: не определено.
6. Какие направления нужны сейчас? Например: разработка, тексты, исследования,
   операции. Как называются они в твоём проекте?
   Ответ: не определено.

## Самостоятельность и проверка

7. Что агент может выполнять сам? Какие действия требуют твоего решения?
   Есть ли уже данное разрешение для текущей задачи?
   Ответ: не определено.
8. Для каких результатов обязателен отдельный проверяющий? Доступны ли
   отдельные агенты в рабочей среде?
   Ответ: не определено.
9. Какие проверки подтверждают готовность: тесты, сверка источников,
   просмотр файла, работающая ссылка? Где описаны команды?
   Ответ: не определено.

## Среда и выдача

10. Где ты работаешь: Codex, Claude Code или оба? Какая операционная система?
    Ответ: не определено.
11. Какие сервисы уже подключены и для чего? Укажи только назначение
    и проверенный уровень доступа, без секретов.
    Ответ: не определено.
12. На каком языке и в каком виде нужен результат? Как сохранять задачи
    и точку продолжения?
    Ответ: не определено.
