# Независимая проверка

Проверяющий — другой агент, который не создавал результат. Он получает точную
версию, задание, критерии, источники, решения пользователя и ограничения.
При недоступности отдельного агента независимая проверка остаётся невыполненной.

Проверь смысл и соответствие задаче, фактические опоры, ясность результата,
требования формата, ссылки и разрешения. Для кода проверь поведение, вызывающие
места и свидетельства тестов; для текста — точность слов, связность, логику,
уровень читателя и ритм. Не проверяй все области проекта при узкой задаче.

В отчёте укажи каждый применимый пункт и конкретный результат, реальные дефекты,
что осталось непроверенным и вердикт: `pass`, `revise` или `blocked`.
Формулировка «всё хорошо» без проверенных пунктов не является отчётом.
Для файлов зафиксируй SHA-256 или точный commit проверенной версии.
Не исправляй файлы во время приёмки. Новая версия требует новой проверки;
изменение роли в одном чате не создаёт независимости.
Приёмка не означает принятия пользователем или разрешения внешнего действия.
