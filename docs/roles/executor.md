# Пакет исполнителя

Координатор передаёт только контекст текущей задачи:
- результат, формат, аудиторию и её уровень знаний;
- границы изменения и критерии готовности;
- прочитанные факты с источниками, нужные выдержки и разрешения;
- применимые правила, принятый пример, прямые исключения и последние отказы;
- точные входные и выходные файлы, доступные проверки.

`templates/brief.md` помогает собрать пакет. Ссылки «прочитай всё в проекте»
не заменяют нужные требования. Узкому исполнителю не нужны NOW и полная история,
если они не меняют его решения.

Исполнитель читает пакет и необходимые первичные материалы. Делает свою часть,
проверяет её и возвращает результат с ограничениями. При нехватке факта
называет пробел. Не публикует, не меняет соседние области и не делегирует
дальше без основания в задаче.
