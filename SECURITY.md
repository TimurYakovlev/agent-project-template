# Данные и распространение

Шаблон не требует ключей и сетевого доступа для локальных проверок.
Подключай сервисы отдельно в своей среде. Ключи, пароли, cookies, SSH-ключи,
session-файлы, клиентские выгрузки и рабочие переписки остаются за пределами Git.
Локальные ответы и резервные копии можно хранить в игнорируемой папке `.local/`.

Перед commit проверь список подготовленных файлов и diff.
`python -X utf8 scripts/check.py` проверяет кандидатов Git, включая уже
отслеживаемые файлы, которые позже попали в .gitignore. Без Git скрипт проверяет
файлы дерева, пропуская служебные каталоги. Он сообщает только путь, строку
и тип находки, без значения секрета.

Проверка ищет распространённые сигнатуры и опасные имена файлов. Она не
обнаруживает все секреты и персональные данные, не исследует историю Git
и не заменяет ручной просмотр. Перед открытием репозитория проверь также
историю, вложения, имена аккаунтов и тексты ответов на анкету.
`.gitignore` не удаляет ранее опубликованное. Раскрытый секрет нужно отозвать.

Ошибку с чувствительными данными обсуждай через приватный канал владельца
репозитория. Не прикладывай значение секрета к issue, pull request или логу.
